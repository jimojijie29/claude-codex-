# 0004 诊断并修复东方财富接口的连接失败

- **代码仓库**：`jimojijie29/Vibe-Trading-William`，基于 `william`
- **分支**：`codex/0004-eastmoney-network`
- **依赖**：无

## 背景

任务 0002 的实测显示，用户机器上美股、港股回测基本跑不通。Yahoo 限流出口 IP，这一条改不了；后备源 akshare 调用东方财富接口时频繁报 `ProxyError / RemoteDisconnected`，同一个调用时成时败，港股一次都没成功。后备源不稳定，美股、港股回测就不可用。

用户的网络环境：使用代理，模式是"绕过大陆"（大陆站点直连，其余走代理）。

## 目标

找出东方财富接口连接失败的真实原因，让 akshare 的美股、港股取数在用户机器上稳定可用；如果原因在项目代码之外，给出用户能照做的处理办法。

## 第一步：诊断（必须先做，不要直接改代码）

目前有三种可能，还没有证据支持其中任何一种，请逐一排除：

1. **请求实际走了代理**。错误名是 `ProxyError`，说明 Python 的请求经过了代理，尽管代理模式是"绕过大陆"。Windows 上 `requests` 会读取环境变量 `HTTP_PROXY`、`HTTPS_PROXY`、`ALL_PROXY`、`NO_PROXY`，没有时读系统代理设置；如果系统代理指向本地代理端口，所有 Python 请求都会先进本地代理，再由代理软件按规则分流。请查清：
   - 相关环境变量的值，以及 `urllib.request.getproxies()` 的返回值（端口可以贴，账号密码不要贴）
   - akshare 的美股、港股历史行情接口实际请求的域名
   - 对这些域名，强制直连（`proxies={"http": None, "https": None}` 或 `session.trust_env = False`）与默认方式各请求 10 次，成功多少次、失败的错误是什么
2. **东方财富的反爬限制**。直连同样会被断开时属于这一类。请查清失败是否与请求频率有关：间隔 0 秒、1 秒、3 秒各连续请求 10 次的成功率。
3. **akshare 版本问题**。记录当前安装的 akshare 版本，查它的更新记录里是否有针对东方财富接口断连的修复，升级到最新版后重测一次成功率。

回报里要有一张表：每种条件下请求了多少次、成功多少次。结论必须由这张表支持。

## 第二步：按诊断结果处理

| 诊断结论 | 处理 |
| --- | --- |
| 走代理导致失败，直连稳定 | 在 `agent/backtest/loaders/akshare_loader.py` 里让东方财富的请求绕过代理。做成可配置：环境变量 `AKSHARE_BYPASS_PROXY`，默认开启，并写进 `agent/.env.example`。不要改全局环境变量，不要影响其他加载器（`ccxt_loader.py` 有自己的代理逻辑，可参考其做法但不要改它）。 |
| 反爬限制，降低频率后稳定 | 在 akshare 加载器里对美股、港股取数加请求间隔和有限次数的重试（带退避），次数和间隔可配置，默认值以你测出的数据为依据。 |
| 升级 akshare 后稳定 | 提高 `pyproject.toml` 和 `agent/requirements.txt` 里 akshare 的版本下限，回报里给出依据。 |
| 多个原因并存 | 分别处理，每项都要有对应的数据。 |
| 以上都不能让它稳定 | 不要硬改。把结果标为 `受阻`，写清测过什么、数据是什么、你建议的方向（例如换一个港股、美股的后备数据源）。 |

## 范围

`agent/backtest/loaders/akshare_loader.py`、它的测试、`.env.example`、必要时的依赖版本下限。

范围外：不改 `runner.py`（0002 返工正在改它），不改后备链顺序，不改 yfinance 加载器，不新增数据源，不修改用户的系统代理或代理软件配置。

## 验收标准

1. 回报包含诊断数据表，结论与数据一致。
2. 修复后在用户机器上实测：`AAPL.US` 和 `700.HK` 各通过 akshare 加载器取 `2024-01-02` 至 `2024-03-01` 的日线，各连续跑 10 次，贴出成功次数、返回行数和首末日期。目标是 10 次里至少成功 9 次；达不到就如实写达到了多少。
3. 新增逻辑有不联网的单元测试（标记 `pytest.mark.unit`），覆盖开关开启、关闭两种情况。
4. `cd agent && python -m pytest tests/test_akshare_loader.py -q --disable-socket` 以及新增测试全部通过。
5. 回报里不出现代理账号、密码、订阅地址等敏感信息。
